หน่วยวิวัฒนาการของอารยธรรมไม่ใช่สิ่งประดิษฐ์ — แต่คืออินเทอร์เฟซ

เราเข้าใจว่าประวัติศาสตร์เทคโนโลยีคือประวัติศาสตร์ของการประดิษฐ์ ไม่ใช่ สิ่งประดิษฐ์คือการกลายพันธุ์ ส่วนใหญ่ตายในห้องทดลอง สิ่งที่ถูกคัดเลือกจริง สิ่งที่ดัดโค้งวิถีของมนุษยชาติ คืออินเทอร์เฟซ

อินเทอร์เฟซไม่ใช่เทคโนโลยี มันคือไวยากรณ์ระหว่างเทคโนโลยี — มันกำหนดว่าระบบแปลกหน้าสองระบบจะจับมือกันอย่างไร อักษรที่รวมเป็นหนึ่งและความกว้างเพลาที่เป็นมาตรฐานคืออินเทอร์เฟซของจักรวรรดิ ตู้คอนเทนเนอร์คืออินเทอร์เฟซระหว่างเรือกับท่าเรือ TCP/IP คืออินเทอร์เฟซระหว่างเครื่องจักร HTTP คืออินเทอร์เฟซระหว่างหน้ากระดาษโลกดิจิทัล

เมื่ออินเทอร์เฟซกลายเป็นมาตรฐาน นวัตกรรมก็เริ่มทบต้น คอนเทนเนอร์ไม่ได้ขนของแม้แต่ชิ้นเดียว มันเพียงเปลี่ยนวิธีจับมือ — แต่ตัดต้นทุนการขนส่งทางทะเลลงกว่าเก้าสิบเปอร์เซ็นต์ และจัดแผนการแบ่งงานระดับโลกใหม่ทั้งหมด HTTP ไม่ได้ผลิตเนื้อหาใด มันเพียงวางกติกา — และทุกสิ่งบนอินเทอร์เน็ตเติบโตบนนั้น

อินเทอร์เฟซคืออำนาจ ผู้ใดนิยามอินเทอร์เฟซ ผู้นั้นเก็บค่าเช่าจากทุกฝั่งปลายน้ำ สงครามมาตรฐานไม่ได้ชนะโดยสิ่งที่ดีที่สุด แต่ชนะโดยสิ่งที่ถูกใช้มากที่สุด QWERTY ระบบปฏิบัติการเดสก์ท็อป พอร์ตชาร์จที่ไม่เปลี่ยนยี่สิบปี — ไม่ใช่คำตอบที่เหมาะที่สุด แต่คือการล็อกตัวเอง

ชีววิทยาเล่าเรื่องเดียวกัน อินเทอร์เฟซอันยิ่งใหญ่ของชีวิตมีเพียงสาม DNA คืออินเทอร์เฟซระหว่างยุคสมัย ATP คืออินเทอร์เฟซของเงินตราพลังงาน ไซแนปส์คืออินเทอร์เฟซของระบบประสาท สี่พันล้านปีไม่เคยถูกแทนที่ ไม่ใช่เพราะมันเหมาะที่สุด แต่เพราะทุกสิ่งปลายน้ำเติบโตบนมัน — ขยับไม่ได้แล้ว

การตัดสินอนาคตของเทคโนโลยี อย่าถามว่ามันทรงพลังแค่ไหน จงถามว่ามันเป็นอินเทอร์เฟซของอะไร มันให้ใครเติบโตบนตัวมันโดยตรง โดยไม่ต้องขออนุญาต

ชะตากรรมของสิ่งประดิษฐ์คือถูกแทนที่ด้วยสิ่งประดิษฐ์ที่ดีกว่า ชะตากรรมของอินเทอร์เฟซคือกลายเป็นสิ่งแวดล้อม — ละลายหายไปในการใช้งาน กลายเป็นสมมติฐานที่ไม่มีใครคิดถึงอีก

สิ่งประดิษฐ์ถูกลืม อินเทอร์เฟซกลายเป็นสัญชาตญาณ
