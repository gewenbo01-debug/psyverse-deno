# Uma missão: os problemas reais são o único calibrador

A doença da civilização não é a falta de tecnologia. É a tecnologia apontada para problemas falsos.

Os problemas falsos partilham três sinais. Resolva um, e ninguém sofre. Não recai sobre nenhuma pessoa concreta — não tem endereço. E existe para si mesmo: nasce para um artigo, nasce para um financiamento, nasce para uma demonstração. Os problemas falsos alimentam grandes organizações, e as organizações alimentam-nos de volta.

Os problemas reais têm três provas. Remova um, e alguém sofre. Tem nome e endereço — abate-se sobre pessoas concretas. Resolva-o, e o tempo é devolvido: as horas gastas a contorná-lo regressam e empregam-se noutra coisa.

A ciência, a tecnologia, a engenharia são três estações de uma mesma linha. A ciência descobre as leis. A tecnologia amplifica-as. A engenharia entrega o amplificado, com estabilidade, a mãos concretas. Falta uma estação, e o problema fica por resolver: sem ciência é força bruta; sem tecnologia, discurso vazio; sem engenharia, uma demonstração. A maioria dos fracassos não é falta de inteligência — é uma estação ausente.

Por isso a missão não é um slogan, é um calibrador. A escolha do tema, a contratação, o investimento, as horas de hoje — tudo passa pela mesma pergunta: que problema real resolve isto? O que não tem resposta fabrica ruído.

Quanto mais barato o cálculo, mais afiada fica a pergunta. A AGI empurra o custo marginal da produção para o zero, e a produção de problemas falsos explode com ele: numa noite, mil artefactos plausíveis. Quanto mais fácil é gerar, mais caro se torna julgar o que merece ser gerado. O calibrador valoriza-se.

Dezasseis visões começam aqui. Por alta que seja a escada, o primeiro degrau é este único alicerce: resolver problemas reais com ciência, tecnologia e engenharia.

Um ponto torna-se caminho; o caminho torna-se uma vida; uma vida torna-se uma linhagem.
