La connaissance a une demi-vie — la pourriture commence au moment où l'on cesse d'apprendre

La connaissance se comporte comme un élément radioactif : elle ne se périmé pas d'un coup, elle décroît exponentiellement. À chaque demi-vie, la moitié devient n'importe quoi.

Les demi-vies varient selon les domaines. L'actualité : vingt-quatre heures. La documentation de framework : dix-huit mois. Le savoir d'ingénieur : environ dix ans. Le savoir médical : sept. Les domaines à la demi-vie la plus courte sont précisément ceux qui courent le plus vite. La mathématique se compte en millénaires, parce qu'elle ne garde que ce qui ne pourrit pas.

Aussi « j'ai fini d'apprendre » est un état qui n'existe pas. Le diplôme n'est pas un récipient de savoir ; c'est un instantané pris le jour de l'entrée — les instantanés jaunissent, et le laboratoire ferme.

Le mécanisme tient en une ligne : le métabolisme du savoir n'est pas un défaut, c'est le moteur. Que d'anciennes conclusions soient renversées prouve que le domaine respire ; qu'une demi-vie raccourcisse prouve que la civilisation accélère. L'ingénieur qui se plaint que le savoir expire se plaint en réalité que la profession soit vivante.

Trois corollaires. Un : le cœur de l'éducation n'est pas de transmettre des faits, mais d'installer l'habitude de les mettre à jour — quatre ans ne peuvent pas enseigner une carrière de quarante ans, mais peuvent apprendre à réapprendre chaque semaine. Deux : le savoir personnel est un flux, pas un stock — le niveau se tient par l'apport continu ; cesser d'apprendre n'est pas rester sur place, c'est commencer une marée descendante exponentielle. Trois : les organisations ont besoin d'une chaîne du froid pour le savoir — documentation, rétrospectives, rituels de passation : toute la logistique frigorifique qui prolonge la vie des connaissances.

Dans le savoir, une seule part est immortelle : la méthodologie. Les faits pourrissent ; la méthode qui remplace les faits est son propre conservateur.

La connaissance a une demi-vie. Il n'existe qu'une seule façon de rester frais : continuer de couler.
