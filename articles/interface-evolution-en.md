Civilization's Unit of Evolution Is Not the Invention — It Is the Interface

We assume the history of technology is a history of inventions. It is not. Inventions are mutations; the vast majority die in the laboratory. What actually gets selected, what bends the trajectory of the species, is the interface.

An interface is not a technology. It is the grammar between technologies — it defines how two alien systems shake hands. Common script and standard axle width were an empire's interfaces. The shipping container is the interface between ship and port. TCP/IP is the interface between machines. HTTP is the interface between pages.

Once an interface standardizes, innovation compounds. The container moves no cargo; it only changes the handshake — and it cut shipping costs by more than ninety percent, reorganizing the global division of labor. HTTP produces no content; it only sets rules — and everything on the internet grew on top of it.

The interface is power. Whoever defines the interface collects rent from everyone downstream. Standards wars are not won by the best; they are won by the most used: QWERTY, desktop operating systems, charging ports unchanged for twenty years — not the optimum, the lock-in.

Biology tells the same story. Life's truly great interfaces number three: DNA is the interface between generations, ATP the interface of energy currency, the synapse the interface of the nervous system. Four billion years, never replaced — not because they are optimal, but because everything downstream grew on them. They can no longer be moved.

So to judge a technology's future, do not ask how powerful it is. Ask what it is an interface to: whom it lets grow directly on top of it, without asking permission.

An invention's fate is to be replaced by a better invention. An interface's fate is to become environment — to disappear into use, to become a premise no one thinks about.

Inventions get forgotten. Interfaces become instinct.
