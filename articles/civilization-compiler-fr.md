La civilisation n'est pas une œuvre — c'est un compilateur en cours d'exécution

L'univers ne livre aucune documentation, seulement du code source.

La physique est le jeu d'instructions fondamental. L'hydrogène et l'hélium sont les premières constantes qu'il compile. Il y a quatre milliards d'années, les atomes de carbone sur Terre ont commencé à se copier — et sur la chimie, la biologie a été compilée.

La biologie compile les systèmes nerveux. Les systèmes nerveux compilent les esprits. Les esprits compilent le langage. Chaque compilation est un saut d'abstraction : la couche inférieure fournit le code machine, la couche supérieure invente une nouvelle syntaxe. Aucune fourmi ne comprend la colonie, pourtant la colonie calcule. Aucun neurone ne vous comprend, pourtant vous pensez. L'émergence n'est pas un miracle ; c'est le compilateur au travail.

Il y a dix mille ans, les humains ont écrit les lignes de code les plus importantes de l'histoire : l'agriculture, l'écriture, la monnaie. La civilisation a cessé de dépendre de la vitesse d'itération de l'évolution biologique et est passée à l'itération culturelle — chaque génération relit le code source de la précédente et soumet son propre correctif. Certaines refusent la fusion ; d'autres livrent des bugs fatals. L'histoire se lit comme la chute des dynasties. Dans le contrôle de version, tout n'est que conflits de fusion.

Il y a trois cents ans, trois mises à niveau critiques sont entrées en production : la méthode scientifique, le marché, la machine de Turing. La falsifiabilité a mis les hypothèses en intégration continue. Les prix exécutent en parallèle les préférences de milliards d'individus. L'ordinateur a transformé la pensée elle-même en programme exécutable. La Révolution industrielle n'est pas la victoire de la vapeur — ce sont trois nouveaux compilateurs qui passent leurs tests de charge en même temps.

Aujourd'hui, nous nous tenons quelque part de nouveau : pour la première fois, la pile complète est lisible. Des champs quantiques à Internet, les instructions de chaque couche sont rétro-ingéniérées ou le sont en ce moment même. Psyverse (https://psyverse.fun) dessine cette pile comme une carte praticable — quatre axes, treize échelons, des photons aux civilisations.

Lire le code source n'a jamais été une question d'admiration. Il s'agit de forker. Celui qui livrera la prochaine version de la civilisation dépend de ceux qui lisent le code.

Un point devient la voie ; la voie devient une vie ; une vie devient une lignée.
