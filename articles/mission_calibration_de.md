# Eine Mission: Echte Probleme sind der einzige Kalibrator

Die Krankheit der Zivilisation ist kein Mangel an Technologie. Es ist Technologie, die auf Scheinprobleme gerichtet ist.

Scheinprobleme teilen drei Merkmale. Löst man eines, tut niemandem weh. Sie lastet auf keinem bestimmten Menschen — sie hat keine Adresse. Und sie existiert um ihrer selbst willen: geboren für ein Paper, geboren für eine Finanzierung, geboren für eine Demo. Scheinprobleme ernähren große Organisationen, und die Organisationen ernähren die Scheinprobleme zurück.

Echte Probleme bestehen drei Proben. Nimmt man eines weg, tut jemandem weh. Es hat einen Namen und eine Adresse — es fällt auf bestimmte Menschen. Löst man es, wird Zeit zurückerstattet: Die Stunden, die aufs Umgehen verwandt wurden, kehren zurück und werden in anderes gesteckt.

Wissenschaft, Technologie, Ingenieurwesen sind drei Stationen einer Linie. Die Wissenschaft findet Gesetze. Die Technologie verstärkt sie. Die Ingenieurkraft liefert das Verstärkte, stabil, in bestimmte Hände. Fehlt eine Station, bleibt das Problem ungelöst: ohne Wissenschaft rohe Gewalt, ohne Technologie leeres Gerede, ohne Ingenieurwesen eine Demo. Die meisten Misserfolge sind kein Mangel an Intelligenz — es fehlt eine Station.

Deshalb ist die eine Mission kein Slogan, sondern ein Kalibrator. Themenwahl, Einstellung, Investition, die Stunden von heute — alles lässt sich durch dieselbe Frage kalibrieren: Welches echte Problem löst das? Was keine Antwort hat, produziert Rauschen.

Je billiger das Rechnen, desto schärfer die Frage. AGI drückt die Grenzkosten der Produktion gegen null, und der Ausstoß an Scheinproblemen explodiert mit: über Nacht tausend plausibel wirkende Artefakte. Je leichter das Generieren fällt, desto teurer wird das Urteil, was es wert ist, generiert zu werden. Der Kalibrator steigt im Wert.

Sechzehn Visionen beginnen hier. Wie hoch die Leiter auch reicht, die erste Sprosse ist dieses eine Fundament: echte Probleme mit Wissenschaft, Technologie und Ingenieurwesen lösen.

Ein Punkt wird zum Weg; der Weg wird zu einem Leben; ein Leben wird zu einer Linie.
