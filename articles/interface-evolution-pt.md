A unidade de evolução da civilização não é a invenção — é a interface

Achamos que a história da tecnologia é uma história de invenções. Não é. Invenções são mutações; a esmagadora maioria morre no laboratório. O que de fato é selecionado, o que curva a trajetória da espécie, é a interface.

Uma interface não é uma tecnologia. É a gramática entre tecnologias — define como dois sistemas estranhos apertam as mãos. A escrita unificada e a bitola padrão eram as interfaces de um império. O contêiner marítimo é a interface entre o navio e o porto. O TCP/IP é a interface das máquinas entre si. O HTTP é a interface das páginas.

Assim que uma interface se padroniza, a inovação passa a render juros compostos. O contêiner não move uma única carga; só muda o aperto de mão — e cortou o custo do frete marítimo em mais de noventa por cento, reorganizando a divisão mundial do trabalho. O HTTP não produz conteúdo algum; só fixa regras — e tudo na internet cresceu sobre ele.

A interface é poder. Quem define a interface cobra aluguel de todo o que está a jusante. As guerras de padrões não são ganhas pelo melhor; são ganhas pelo mais usado: QWERTY, os sistemas operacionais de desktop, as portas de carregamento vinte anos sem mudar — não é o ótimo, é o lock-in.

A biologia conta a mesma história. As interfaces verdadeiramente grandes da vida são três: o DNA é a interface entre gerações, o ATP a interface da moeda energética, a sinapse a interface do sistema nervoso. Quatro bilhões de anos sem troca. Não por serem ótimas, mas porque tudo a jusante cresceu sobre elas. Já não dá para movê-las.

Para julgar o futuro de uma tecnologia, não pergunte quão poderosa ela é. Pergunte interface de quê ela é: a quem ela permite crescer diretamente por cima, sem pedir licença.

O destino de uma invenção é ser substituída por uma invenção melhor. O destino de uma interface é virar ambiente — desaparecer no uso, virar uma premissa sobre a qual ninguém mais pensa.

Invenções são esquecidas. Interfaces viram instinto.
