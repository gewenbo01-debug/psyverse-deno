# Uma missão: os problemas reais são o único calibrador

A doença da civilização não é falta de tecnologia. É tecnologia apontada para problemas falsos.

Problemas falsos têm três sinais. Resolva um, e ninguém sente falta. Ele não recai sobre nenhuma pessoa concreta — não tem endereço. E existe em função de si mesmo: nasce para um paper, nasce para um aporte, nasce para uma demo. Problemas falsos alimentam organizações grandes, e as organizações retribuem o alimento.

Problemas reais têm três provas. Tire um do ar, e alguém sente dor. Ele tem nome e endereço — cai sobre pessoas específicas. Resolva-o, e o tempo volta: as horas gastas para contorná-lo retornam e vão para outra coisa.

Ciência, tecnologia e engenharia são três estações de uma mesma linha. A ciência descobre as leis. A tecnologia as amplifica. A engenharia entrega o amplificado, com estabilidade, nas mãos certas. Falta uma estação, e o problema continua em aberto: sem ciência é força bruta; sem tecnologia, conversa vazia; sem engenharia, uma demo. A maioria dos fracassos não é falta de inteligência — é uma estação ausente.

Por isso a missão não é slogan, é calibrador. Escolha de tema, contratação, investimento, as horas de hoje — tudo passa pela mesma pergunta: que problema real isto resolve? O que não tem resposta está fabricando ruído.

Quanto mais barato o processamento, mais afiada fica a pergunta. A AGI empurra o custo marginal de produção para o zero, e a produção de problemas falsos explode junto: em uma noite, mil artefatos verossímeis. Quanto mais fácil gerar, mais caro fica julgar o que vale a pena gerar. O calibrador se valoriza.

Dezesseis visões começam aqui. Por mais alta que seja a escada, o primeiro degrau é este único alicerce: resolver problemas reais com ciência, tecnologia e engenharia.

Um ponto vira caminho; o caminho vira uma vida; uma vida vira uma linhagem.
